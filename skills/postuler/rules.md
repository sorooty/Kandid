# Rules for every document Kandid writes

## Honesty

- Every skill, tool, experience, figure and date comes from `profile.yaml`. Nothing else, even if the offer asks for
  it and even if it seems minor.
- Tools listed in `rules.unconfirmed_skills` are never claimed as practiced. In a letter they can be named as
  something the user is learning or wants to learn, said plainly.
- Terms in `rules.forbidden_terms` never appear.
- A requirement the profile does not meet is not hidden by vague wording. Leave it out of the CV; in the letter,
  address it honestly only when it matters (for instance: "je n'ai pas encore utilisé X, je m'y forme").
- When unsure whether the profile supports a claim, leave it out and mention it to the user.

## Writing

- Natural, precise, human tone. Short sentences. Concrete facts and results from the profile rather than adjectives.
- No filler ("Je me permets de", "Passionné par"), no superlatives, no generic praise of the company.
- Characters never used in the text you write: em dash, en dash, arrows, middle dot, ellipsis character. Use
  commas, colons, parentheses. The separators the CV template draws between dates are its layout, not your text.
- Same language as the offer unless the user asks otherwise (`lang: fr` or `lang: en` in the spec).
- `rules.letter` in the profile holds the user's own instructions for letters: follow them.

## Privacy

- Read only the profile and the offer needed for this application. Never paste profile content into a web search or
  any tool that leaves the machine, other than Claude itself.
